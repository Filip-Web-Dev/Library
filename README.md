Library Management App

A lightweight web application for managing a personal library, tracking borrowed books, and searching through book collections using Vanilla JavaScript.

Key Features
- Add Books: Easily store new books with title and author details.
- Borrow/Return System: Toggle book availability status and record borrower details via user prompts.
- Delete Functionality: Remove unwanted books from the collection.
- Real-Time Search Filter: Dynamic filtering of books by title or author name.
- Persistent Storage: Books and borrowing status persist across browser sessions using LocalStorage.

Tech Stack
- HTML5: Basic application structure and inputs.
- CSS3: Custom styling and layout design.
- JavaScript (ES6+): DOM manipulation, Event Handling, Array Filtering, and LocalStorage Web API.

Project Context
Created as a practical project to master basic CRUD operations, array manipulations, dynamic UI rendering, and state management using JavaScript's native LocalStorage API.
